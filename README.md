# Function Adventure

Game petualangan edukasi berbasis website untuk membantu siswa SMA/SMK memahami fungsi dan komposisi fungsi melalui eksplorasi dan tantangan matematika.

## Status proyek

Proyek berada pada tahap awal pengembangan. Fitur berikut merupakan rencana, belum implementasi yang selesai.

## Rencana fitur

- Tiga wilayah: Hutan Fungsi, Gua Komposisi, dan Kastel Matematika.
- Peta 2D berbasis grid dengan kontrol keyboard dan tombol sentuh.
- Tantangan fungsi dan komposisi fungsi dengan petunjuk serta pembahasan.
- Sistem skor, gerbang, kunci, dan tantangan akhir.
- Penyimpanan progres menggunakan localStorage.
- Antarmuka berbahasa Indonesia.

## Teknologi

- HTML
- CSS
- JavaScript
- localStorage

Versi awal dirancang tanpa backend atau akun pengguna.

## Target MVP

Pemain dapat menyelesaikan 12 soal, memperoleh tiga kunci, membuka peti harta, melihat hasil akhir, dan melanjutkan progres pada browser yang sama.

## Menjalankan proyek

Berkas aplikasi belum tersedia. Petunjuk menjalankan game akan ditambahkan setelah implementasi awal.
